Recruitment & Placement Management System
Python Project Scope

Project type:
Industry-oriented Python and MySQL backend business application with a console UI.

Implemented modules:
1. Candidate registration, search, validation, skills, and profile status
2. Company registration, search, and status
3. Job creation, search, eligibility criteria, required skills, and status
4. Candidate eligibility verification
5. Job application, duplicate prevention, shortlisting, and application history
6. Interview round scheduling and feedback
7. Offer creation and offer status management
8. Placement registration and joining status
9. Application, job, candidate technology, and placement reports

Architecture:
Console application -> Services/business rules -> DAOs -> MySQL

The eligibility engine checks candidate and company status, job status and
deadline, qualification, percentage, passing year, active backlog count, and
mandatory skills. The workflow progresses from application through interview,
selection, offer, and placement. Status changes and interview outcomes are
recorded in application history.

The static HTML/CSS prototype is in ui-prototype/. It includes login, dashboard,
candidate list/add/details, company, job list/create, application, interview,
placement process, and report pages. Prototype data is hardcoded; the screens
are not connected to this Python backend.

Database configuration is read from RPMS_DB_HOST, RPMS_DB_PORT, RPMS_DB_USER,
RPMS_DB_PASSWORD, RPMS_DB_NAME, and RPMS_ACTOR_USER_ID environment variables.
See README.md for setup and test instructions.
